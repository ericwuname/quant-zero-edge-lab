# Zero-Edge Lab · 零边缘实验室

> 一份在加密货币 1 小时数据上，用几十轮严谨回测**系统性证伪"可提取方向 alpha"**的完整实验记录。
> 以及由此沉淀出的一套**策略判据**——它能在 10 秒内判断任何策略值不值得看。

---

## ⚠️ 这个仓库不是什么

**它不是一个"找到了策略"的项目。**

这里没有一个能实盘的、正期望的方向性择时策略。如果你在找圣杯，这里没有。

它记录的是：**一个人和一套回测框架，用了几十轮、上百个实验，把"找策略"这件事本身证伪了的全过程。**

## 🔑 三个最重要的数字

| 数字 | 含义 |
|---|---|
| **alpha = −0.0003** | 信号 vs 随机方向，同品种、同时点配对检验。信号没有任何方向能力 |
| **波动 t=44 / 方向 t=0.20** | 同一个特征预测波动率极显著，预测方向等于抛硬币 |
| **杠杆 92%** | 2 倍杠杆爆仓率 92%，而**中位数结局是归零**。均值却是正的 |

第三个数字解释了一件事：**为什么"有人赚钱"和"策略无效"可以同时成立。**

## 📐 三大核心判据

### 判据一：期望分解恒等式

```
E = (R + 1) × ( p − 1/(1+R) )
```

实测验证：Δp = +1.09pp → 预测 E = +0.0327，实测 **+0.0321**（误差 0.0006）。

**别看夏普、别看回撤、别看收益曲线。只看"实测胜率 − 保本胜率"。**
R 是放大器——优势被放大，劣势也被放大。

### 判据二：成本锁定

```
cost_R = 2 × cost_bp ÷ (止损% × 10⁴)
```

**止损宽度和成本占比是同一个式子的两端，不能各自独立设定。**
这是本项目中导致最多结论作废的一条。

### 判据三：障碍几何（零期望下白送的胜率）

```
P = (1 − b) / (1 − b + u)
```

亏 80% / 赚 100% → **44.4% 是几何白送的**；对称化后精确回到 **50%**。

> **任何用"P(赚回本金)"证明策略有效的论证，先减掉这 44%。剩下的才是 edge。**

## 🕸️ 唯一站住的：网格交易

网格不属于"预测方向"类，它是**卖波动率 / 卖保险**：震荡收保费，单边赔付。

**关键证据**：在**零漂移合成数据**上（已知没有方向），20 个独立世界：

```
网格净收益 +33,290，t = +4.32
网格 − 买入持有 = +29,296，t = 7.33，20/20 全正
```

**推荐规格**（详见 [`docs/04-网格规格.md`](docs/04-网格规格.md)）：

| 项 | 值 |
|---|---|
| 类型 | 等比网格（区间 > 30% 时） |
| 区间 | ±25% ~ ±30% |
| 格数 N | 资金允许的最大值（每格 ≥ 最小下单额） |
| 离场 | **21 天无成交即平仓**（不是移仓重启） |
| 杠杆 | **1x 现货**（2x 爆仓率 92%） |
| 单店资金 | C = 可承受亏损 ÷ 0.18 |

**预期**：年化中位约 **13%**，回撤中位 **20%**，77% 品种为正，**但仅 38% 跑赢买入持有**。

**它的正确定位**：震荡市的收租工具，不是万能策略。牛市会卖飞，单边下跌会亏损。

## 🧰 方法论：怎么测才可信

这五条是本项目的核心资产，详见 [`docs/05-防过拟合方法.md`](docs/05-防过拟合方法.md)。

**① 零期望对照是必需的，不是可选的**

实测：**45 个纯随机信号，挑出最强的那个，平均 t = +1.963** —— 比真实数据最强的 t = +1.529 还高。

> **t = 1.96 这个"显著"门槛，光靠"多挑几次"就能凭空够到。**

**② 三重外推：时间 / 品种 / 参数**

每次"选中 → 验证"平均衰减 **54% ~ 63%**，选择偏差实测 **0.090R**。
典型症状：同一套参数，OLD7 批次 **+0.0807**，NEW6 批次 **−0.0249**（符号反号）。

**③ 配对检验剥离 beta**

`alpha = E(信号) − E(随机方向)`，同品种、同时点、只换方向。这是唯一干净的方向能力测量。

**④ 实验设计错了会得出假结论**

用"两边都随机方向"测入场点 → 差值数学上必然为 0 → 14 个策略全测出 ≈0。
**那是尺子坏了，不是入场点不重要。**

**⑤ 留存衰减监控**

| 检验 | 结果 |
|---|---|
| 时间切分（前半 / 后半） | 稳定 ✅ |
| 干净样本外推（未参与选择） | **衰减 54~63%** ⚠️ |
| Reality Check | 多数 **p > 0.05** ❌ |

## 🌍 为什么"机构能赚钱"而你不能

```
N_eff = N / (1 + (N−1)ρ)
```

crypto 内部 ρ = 0.497 → **无论加到多少品种，N_eff 上限 = 1/ρ = 2.0**。
你以为有 7 个市场，实际只有 **1.76** 个。机构做 20~50 个低相关市场。

**检测门槛**：需要夏普 **0.673** 才能区分 skill 与 luck。真实数据最优 **0.097**（门槛的 14%）。

> **差距在 N，不在聪明。**

## 🧭 三条不能越过的线

**1. 成本地板**

| 成交方式 | cost_R | 结论 |
|---|---|---|
| maker 2bp | 0.008 ~ 0.027 | 勉强为正 |
| 混合 5bp | 0.046 ~ 0.063 | **全部转负** |
| taker 10bp | 0.040 ~ 0.100 | **全部转负** |

**2. 窄止损地板**

单根 bar 振幅中位 **111 bp**。止损窄于这个量级 → 一根线打穿 → 45.5% 的 bar 走完整个"止损+止盈"区间。

**3. 幸存者偏差**

存活者年化 −3.7%，加回 53.2% 归零者后：**−54.9%**。量级**远超成本**。

## 🤖 关于 LLM / Agent 做交易

本项目测过"让 Agent 判断交易时机"：

```
Agent 离场（ADX>30） 真实超额 +0.042
随机挑最幸运的离场时刻  超额 +0.211
真实 Agent 胜过随机的比例：0/13
```

**随机挑最幸运的离场时刻，超额是真实 Agent 的 3~5 倍。**

原因不是 Agent 笨，是：

$$E[\text{max}] \approx \mu + \sigma\sqrt{2\ln M}$$

> **更聪明 = 搜索空间更大 = 过拟合更严重 = 结果更假，而且假得更漂亮。**

**Agent 的正确定位不是"替你判断"，是"替你执行"**——守住纪律，让它不因情绪失效。
